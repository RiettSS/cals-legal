Cals support

Cals is provided by Artsiom Dzemchanka, an individual developer. Email celenajones01@gmail.com for app support, privacy requests or a shared-product correction. You can also contact the developer on Telegram @kirathecat19.

Pre-release status

Cals is not yet available on the App Store. The current simulator purchase flow is for testing. Privacy and terms pages are review drafts until the release controls and disclosures are finalized.

Age confirmation

Cals is for users aged 19 and older. On Confirm your age, enter an accurate Date of birth and choose Confirm date of birth. The app checks 19+ eligibility before automatic server-profile registration, AI use, catalog access or subscription synchronization. A confirmed date below the threshold displays Cals is for ages 19+. If you already have a profile, use Manage existing server profile to manage privacy or delete it; that path does not create a new profile or enable AI. The date stays on your device; the server receives only the eligibility affirmation, policy version and time linked to the profile. This declaration is separate from AI-sharing permission and does not involve a government-ID check. If you need help correcting a date or reporting an underage submission, contact the email above without sending an identity document.

Tell us what happened

Include the app version, iOS version and a short description of the problem. For a catalog issue, include the product name and barcode. Send a screenshot or food photo only if you choose to and it helps explain the issue.

Keep sensitive information private. Do not send your password, access token, Keychain credential, payment-card details or unnecessary health records. Do not post a private diary or deletion request in a public GitHub issue.

Privacy controls and requests

Open Settings → AI data sharing → Withdraw consent to stop new AI submissions. To delete the server profile, open Settings → Delete server profile; you can choose Manage Apple subscriptions before confirming deletion. Withdrawal blocks new AI requests; an analysis already forwarded to the provider cannot be recalled. Profile deletion removes associated active server records and linked shared contributions while keeping your local diary on the device. Apple subscriptions must be canceled separately; deletion does not stop billing. See the Privacy Policy for the deletion-protection hashes, aggregate counters and separate provider/hosting retention.

A successful deletion is confirmed as Server profile deleted. If the deletion response was interrupted, use Retry deletion. A new profile is created only if you explicitly choose Create new server profile. For access, correction or help with the controls, email Cals privacy request. We will ask only for proportionate information needed to identify the record and handle your request.

Apple subscriptions

When live subscriptions are available, manage billing through Apple. Cancel or manage a subscription, or request an eligible refund. Deleting Cals does not cancel billing. No Cals App Store product is currently live.

Food estimates

Check product labels and quantities before saving. A photo-based weight is an estimate. If precision matters, weigh the portion and enter its amount manually. Cals is not a medical or allergen-safety tool.
